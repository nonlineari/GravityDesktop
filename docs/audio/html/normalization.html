NORMALIZATION

One norm box, shared by the recorder and by gravity. off is the default. Peak and loudness are both constant-gain: the whole programme moves by one amount. Measurement happens after the take is closed, because the gain depends on the whole file.

peak

sample peak → −1.0 dBFS

  1. ffmpeg reads 0:a:0 through volumedetect.
  2. parseMaxVolumeDb keeps the last max_volume line.
  3. gain = −1.0 − max_volume.
  4. Filter is volume=<gain>dB, three decimal places.
  5. A non-finite reading, or a gain smaller than 0.05 dB, writes no filter.

loudness

EBU R128 → −23.0 LUFS · true peak −1.5 dBTP · LRA 11

  1. Pass 1: loudnorm=I=-23:TP=-1.5:LRA=11:print_format=json.
  2. Read input_i, input_tp, input_lra, input_thresh, target_offset.
  3. Pass 2: the same targets plus those measurements and linear=true.
  4. Skip when integrated loudness is already within 0.5 LU and true peak is already at or under −1.5 dBTP.
  5. An -inf measurement writes no filter.

recorder · STOP

rewriteAudioNormalized encodes to a sibling .norm-tmp file, then replaces the take. The filter is followed by soxr 48 kHz. Codec follows the extension: pcm_s24le, pcm_s16le, FLAC, AAC twoloop 256k, or MP3 320k. A failed encode deletes the temp and keeps the original. SAVE waits until this rewrite finishes.

gravity · split

The same filter string is prefixed onto [0:a] before pan and channelsplit. One gain for every channel, so the image stays put. mix.wav is the amerge of those packets. A download MP4 is not rewritten.

SECOND PASS

When gravity runs on a take that STOP just normalized, the measure runs again. A file already on target produces no second filter. The status line says norm held. Silence and a missing audio stream also produce no filter; the split still runs on the original programme.
