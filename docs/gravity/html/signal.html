AUDIOVISUAL SIGNAL

Picture and sound are processed as one media file. ffprobe reads both streams. The four numbers that leave this stage are the audio_vector the tesseract cell carries.

picture

ACQUIREBar URL, drag, or paste. yt-dlp writes ~/Downloads. H.264 is the house picture codec.
PIXELSVP9 and AV1 become H.264 at the same width and height. The convert does not scale the frame down.
GIFA GIF address, Giphy, Tenor, or an X tweet_video takes the GIF path. That file can still be minted.
THETAA non-zero theta rotates into direct-h264-rot<n>-<id>.mp4. The rotated file is the one minted when it exists.
DUALdual vi writes a VP56/webm sibling. The MP4 remains the preview path unless theta replaced it.

sound

RECORDWYHIWYREC, net stream, or catalog. Re-encode is soxr 48 kHz, precision 28. Codecs: pcm_s24le, pcm_s16le, FLAC, AAC 256k, MP3 320k.
NORMAfter STOP, peak sets the sample peak to −1 dBFS. Loudness sets integrated loudness to −23 LUFS with true peak −1.5 dBTP. One gain for the programme.
GRAVITY SPLITIdentity pan, then channelsplit, at most 8 channels, pcm_s24le at 48 kHz. mix.wav is the amerge. Layouts run stereo through 7.1.
METERThe signal meter is a second ffmpeg on the monitor. Its samples are not in the file and not in the audio_vector.
