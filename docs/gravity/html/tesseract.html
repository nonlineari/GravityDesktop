The address space of a minted file. Four binary axes, sixteen vertices. An edge flips exactly one axis: X, Y, Z, or T. Axes are named by the tetragrammaton Y H W H.

HASH → VERTEX

vertex_from_digest reads hex digits 0, 1, 2, 3 of the sha256. The low bit of each digit is x, y, z, t. The same file always returns the same vertex. Cells may hold more than one mint.

HASH → PATTERN

First eight hex digits select one code per axis. Spatial AB AABB ABAB ABBA. Rhythm 2:4 3:3 4:4 5:3. Structure P&B P|B P→B P←B. Transform F1 F2 F3 F4. Owner default is AABB.3:3.P|B.F2.

PROBE → VECTOR

metadata_vector is the audio_vector: duration, size, bitrate, aspect. It is stored on the vertex. It does not choose the vertex. The vertex is the address. The vector is the measurement.

Bits are written x y z t. apriori_loop.py builds this binary-reflected 4-bit Gray code. cycle_next steps one edge. Sigma-9 is the 9-byte GRAVITY handshake that opens the live protocol. It is not a coordinate on this cube.
