POSITION

pos_reconcile joins the audiovisual file to its tesseract cell. AVD is the media. POS is the vertex. A paired entry has both. The proof hashes the index.

AVD · the file

  • Recent downloads and visualist outputs.
  • asc_mode FILMIC, or GRAVITY when the visualist row is gravity_prepared.
  • Sidecar <file>.interlaterus.json supplies sha256, pattern, and vertex when the mint has run.
  • Path, name, and modified time stay with the bytes on disk.

POS · the cell

  • Authoritative vertex map is blockcode_registry.db, keyed by sha256.
  • Each record: pattern_code, vertex [x,y,z,t], media path, source URL, minted time.
  • storage_memory_category adds zone, memory, location, V, and Bandwidth.
  • Interstellar or nonlineari titles use interstellar-zone-alpha. Others use default-zone.

PROOF OF SPATIO

Canonical JSON of the entries, then sha256. The proof records entry count, orphan lists, vertex histogram, and tesseract_capacity 16. Rebuilding the index rebuilds the proof.

OCCUPANCY

Sixteen cells. A content hash may share a cell with another file. vertex_histogram counts how many paired records sit on each vertex. Orphans are AVD without POS, or POS without a file still on disk.
